# Context Keeper v2 프로젝트 가이드라인

## 핵심 철학
이 프로젝트의 목표는 단순한 챗봇이 아니다. 우리는 상태 기반(Stateful) 지능형 에이전트를 구축하는 것을 목표로 한다. 에이전트는 능동적(Proactive), 효율적(Efficient), 그리고 투명(Transparent)해야 한다.

## 아키텍처 원칙
1.  **모듈성**: 모든 기능은 명확하게 분리된 모듈(UI, Graph, Data, Tools)에 존재해야 한다.
2.  **상태 중심**: 모든 정보 흐름의 중심에는 AgentState가 있어야 한다.
3.  **점진적 확장**: 한 번에 모든 것을 구현하려 하지 말고, 안정적인 기반 위에 기능을 점진적으로 추가한다.
